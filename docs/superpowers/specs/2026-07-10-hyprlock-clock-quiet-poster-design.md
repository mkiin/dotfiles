# hyprlock 時計の Quiet Poster 案

- 対象: `home-manager/desktop/hyprland/hyprlock.conf`、`home-manager/desktop/hyprland/scripts/lock/lock-clock.sh`、`home-manager/desktop/hyprland/lock-colors.template.conf`
- 合意日: 2026-07-10
- 採用案: A1 Quiet Poster / Short Rule

## 背景

現在のロック画面は、暖色のイラスト壁紙、左下の時計、中央の入力欄で構成している。

直近の設定では、時計に JetBrainsMono Nerd Font SemiBold を使い、時刻を大きく出し、コロンと分にアクセント色を使っている。
この方向は視認性が高い一方で、添付画像のように人物の顔と暖色背景が強い壁紙では、時計の橙が装飾として目立ちすぎる。

今回の設計では、壁紙を主役に戻しつつ、OSD らしい情報表示の硬さを少し残す。
そのため、時刻の数字は単色にし、アクセント色は短い罫線と曜日だけに限定する。

## 採用する見た目

**Quiet Poster** は、左下に大きな時刻を置く構成を維持しながら、色の主張を抑えた表示である。
時刻、短い罫線、日付を縦に積み、時計ブロックの輪郭を罫線で作る。

```text
05:02 PM
------
FRI / JUL 10
```

橙はコロンや分には使わない。
橙を数字の一部に使うと、時刻そのものが装飾になる。
短い罫線と曜日にだけ使うと、時計ブロックの構造を示す色として働く。

## フォント

時刻には Inter Display Medium を使う。
実機で hyprlock が Inter Display を解決できない場合だけ、Inter Medium にフォールバックする。
太さは Medium とし、SemiBold にはしない。
現状の JetBrainsMono Nerd Font SemiBold よりも柔らかく、壁紙のイラスト感に寄せるためである。

日付には JetBrainsMono Nerd Font Medium を使う。
日付だけをモノスペースにすることで、OSD らしい情報表示の硬さを残す。
時刻と日付の両方をモノスペースにすると、画面全体がガジェット寄りに傾きすぎる。

AM/PM は時刻ラベル内の小さな span として右肩に置く。
色は `$lock_ampm` を使い、時刻よりも低いコントラストにする。

## レイアウト

時計ブロックは左下固定の縦積みにする。
順序は、時刻、短い罫線、日付である。

時刻は現状の `font_size = 150` より小さくする。
候補値は `130` から `140` の範囲とし、実機プレビューで確定する。
左下の存在感は残すが、人物の顔とリボンへの干渉を減らすためである。

日付は時刻の下に従属させる。
形式は `FRI / JUL 10` とする。
中点ではなくスラッシュを使う。
理由は、短い罫線と組み合わせたときに、日付行がラベルとして読めるためである。

罫線は hyprlock の `shape` ウィジェットで作る。
幅は時刻幅よりかなり短くし、時計ブロックの左端に揃える。
候補値は `90 x 4` 前後とし、実機プレビューで確定する。

## 装飾と色

背景画像、左下 scrim、シャドウ、入力欄は維持する。
今回の変更対象は時計と日付の表示だけである。

色トークンは matugen 由来を維持する。
新しい固定色は追加しない。

| 役割       | トークン       | 用途                 |
| ---------- | -------------- | -------------------- |
| 時刻       | `$lock_time`   | `05:02` の数字全体   |
| 罫線と曜日 | `$lock_accent` | 短い罫線と `FRI`     |
| AM/PM      | `$lock_ampm`   | 右肩の `PM`          |
| 日付       | `$lock_date`   | `/ JUL 10`           |
| 影         | `$lock_shadow` | 時計と日付のシャドウ |

`$lock_accent` は時刻のコロンと分には使わない。
この制約を置くことで、アクセント色の役割を装飾から構造へ寄せる。

## 変更対象

`hyprlock.conf` では、時刻ラベルのフォント、サイズ、位置を更新し、罫線用の `shape` を追加する。
日付ラベルはフォント、サイズ、位置を更新する。
入力欄の設定は変更しない。

`lock-clock.sh` では、`time` モードを単色時刻と低コントラストの AM/PM にする。
`date` モードは `FRI / JUL 10` 形式にする。
曜日だけ `$lock_accent` にし、残りを `$lock_date` にする。

`lock-colors.template.conf` は変更しない。
既存の `$lock_time`、`$lock_accent`、`$lock_ampm`、`$lock_date` だけで今回の色設計を表現できるためである。

## 実機調整

座標とサイズは `lock-preview.sh` のスクリーンショットで確定する。
最初の候補値は以下とする。

| 要素         | 候補値                                 |
| ------------ | -------------------------------------- |
| 時刻フォント | Inter Display Medium                   |
| 時刻サイズ   | 135                                    |
| 日付フォント | JetBrainsMono Nerd Font Medium         |
| 日付サイズ   | 25 から 28                             |
| 罫線         | 幅 90、高さ 4、角丸 2                  |
| 時計位置     | 現状より少し上、左端は現状維持に近い値 |
| 日付位置     | 罫線の下、左端は時刻と揃える           |

実機で見て、人物の顔と中央入力欄への干渉が強い場合は、時計全体を 5 から 15px 下げるか、時刻サイズを 130 まで下げる。
日付が弱すぎる場合は、日付サイズを上げるのではなく `$lock_date` のアルファを上げる。

## 受け入れ基準

- 左下に Inter 系の単色時刻、短い橙罫線、`FRI / JUL 10` の日付が縦積みで表示される。
- コロンと分は `$lock_accent` ではなく `$lock_time` で表示される。
- アクセント色は短い罫線と曜日だけに使われる。
- 日付は JetBrainsMono Nerd Font Medium で表示され、OSD らしい硬さを残す。
- 入力欄、背景、scrim、アニメーションは変更されない。
- `LOCK_CLOCK_AT=2026-09-23` のような長めの日付でも左下の表示が崩れない。
- `nix run .#build` と `nix run .#fmt -- --fail-on-change` が成功する。
