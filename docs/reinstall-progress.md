# インストーラーの状況

## 実装

- `installer/apps/install.nix`：SSD選択、パスワード・rclone設定、本番環境の導入。
- `installer/apps/reinstall.nix`：復旧ファイルの作成と、パスフレーズによる復元。OS導入は`install`を呼ぶ。
- 公開鍵は`secrets/host-keys.nix`、選んだSSDのby-idは各ホストの`disko.nix`へ直接書く。
- 更新した設定と暗号文は、インストール先のdotfilesに保存する。
- `.nu`ファイルは作成していない。`checked`関数の3行だけが重複している。

使い方は[インストール手順](reinstall-operations.md)を参照。

## 検証

- 両アプリのビルドとNu構文検査。
- 両ホストのdry-run、不明なホスト・オプションの拒否。
- 模擬ディスクでのマウント・swap使用中の消去拒否、再開時の親ディスク照合。
- テスト鍵を使ったageの暗号化・復号、上書き後の復号。
- 生成したNixファイルの評価と、ホスト公開鍵・ディスクIDの確認。
- テストデータでのパスフレーズ付き復旧ファイルの作成・復号照合。

自動テストは`nix flake check ./installer`で実行する。

## 未実施

- 実際のSSD消去、OS導入、再起動・ログイン・GPU・ネットワークの確認。
- VM試験。以前のユーザー判断どおり省略。

復旧ファイルはまだリポジトリにない。そのまま再インストールを実行すると、ディスク操作前に停止する。
